# CLAUDE.md — правила проекта

## Общение
- Общаться с пользователем только на русском.

## Технологии
- Чистый HTML / CSS / JS. Без React, без сборщиков, без npm-зависимостей.
- Основные файлы: `index.html`, `style.css`, `script.js`. Картинки — только в `assets/`.
- Деплой — GitHub Pages из корня ветки `main`: https://slavinator07.github.io/poet-site/ (репозиторий `Slavinator07/poet-site`).

## Правила

1. **Проект** — сайт со стихами автора.
2. **Стиль** — премиальный, поэтичный, без визуального шума. Оттенки чёрного и белого, лёгкость, редкие явные акценты. Цвета — только через CSS-переменные в `:root`.
3. **Главный экран (Hero)** — обязательно есть анимированная/интерактивная часть, связанная со стихами и поэзией. Печатная машинка не обязательна. Если машинку оставляем — она должна быть максимально реалистичной (не схематичной/мультяшной).
4. **Ежедневная программа** — см. раздел ниже.
5. **Публикация на основной сайт — только после одобрения пользователя.** Черновики можно публиковать в `drafts/` (это не меняет главную страницу). После одобрения: перенести выбранный вариант в `index.html`/`style.css`/`script.js`, `git commit` и `git push`.

## Ежедневная программа

**Когда:** один раз в день, при первом сообщении пользователя за день в этом проекте (любом). Если пользователь не заходил — день пропускается, не наверстываем. Повторные сообщения в тот же день программу не запускают. Запуск подсказывает хук `.claude/hooks/daily-hero.sh` (дата последнего запуска — `.claude/daily-hero-last-run`).

**Шаги:**
1. Одной строкой предупредить: «Начинаю ежедневную программу пет-проекта — пожалуйста, ничего не пишите, пока я не закончу».
2. Найти **3 референса — по одному с каждого сайта**, из свежих подборок, только удачные:
   - [Awwwards](https://www.awwwards.com/websites/) (новые / Sites of the Day)
   - [Siteinspire](https://www.siteinspire.com/)
   - [One Page Love](https://onepagelove.com/)
   Если на сайте нет ничего нового — взять лучшее за последнюю неделю, что ещё не использовалось.
   Использованные референсы записывать в `drafts/references.md` (дата, сайт, ссылка, что взяли) и не повторять.
3. Сделать **3 варианта Hero — по одному на каждый референс**: `drafts/ГГГГ-ММ-ДД/a.html`, `b.html`, `c.html` + `drafts/ГГГГ-ММ-ДД/index.html` со списком (референс, ссылка на него, что взяли, ссылка на вариант). В черновиках `<meta name="robots" content="noindex">`.
4. **Только десктоп** (1440px). Мобильную версию делаем после одобрения варианта.
5. Каждый вариант соблюдает правила 2–3 (анимация, связанная с поэзией).
6. Проверить варианты в браузере, затем `git commit` + `git push` черновиков (главная страница не меняется).
7. Прислать пользователю: ссылку на `https://slavinator07.github.io/poet-site/drafts/ГГГГ-ММ-ДД/`, три референса и короткое описание каждого варианта. Ждать решения: какой вариант берём / что поменять / оставить как есть.
