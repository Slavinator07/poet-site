# CLAUDE.md — правила проекта

## Технологии
- Чистый HTML / CSS / JS. Без React, без сборщиков, без npm-зависимостей.
- Файлы: `index.html`, `style.css`, `script.js`.
- Деплой — GitHub Pages (статика из корня ветки `main`).

## Правила

1. **Проект** — сайт со стихами автора.
2. **Стиль** — премиальный, поэтичный, без визуального шума.
   - Точной палитры пока нет — решаем в процессе.
   - Базово: оттенки чёрного и белого. Ощущение лёгкости + явные, редкие акценты.
   - Цвета задаются только через CSS-переменные в `:root` (`style.css`), чтобы палитру было легко менять.
3. **Главный экран (Hero)** — обязательно анимация печатной машинки (Typewriter effect). Не удалять при редизайне Hero.
4. **Ежедневное обновление Hero.** Перед каждым обновлением собрать **минимум 5 референсов** с сайтов:
   - [Awwwards](https://www.awwwards.com/) (раздел Recent / Sites of the Day)
   - [Siteinspire](https://www.siteinspire.com/)
   - [One Page Love](https://onepagelove.com/) — **только для одностраничников**, использовать в будущем
   Показать референсы (ссылка + что берём), затем обновить Hero.
5. **После каждого обновления** — `git commit` и `git push`, чтобы результат появился на GitHub Pages.

## Заметки по коду
- Тексты для Typewriter лежат в массиве `lines` в начале `script.js`.
- Уважать `prefers-reduced-motion`: при нём текст показывается сразу, без анимации.
